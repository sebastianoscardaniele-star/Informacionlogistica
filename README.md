# Sellers Tiendas - Vite

Aplicación Vite/React para gestionar sellers por tienda.

## Vercel

- Framework: Vite
- Install Command: `npm install --no-audit --no-fund`
- Build Command: `npm run build`
- Output Directory: `dist`

## Funciones

- Tiendas separadas en pestañas: BNA, Macro y demás solapas incorporadas.
- Datos de sellers editables por secciones.
- Estado editable con desplegable.
- Exportación a XLSX.
- Sin botón de importar.
- Los datos iniciales están embebidos en `src/data.js`.
