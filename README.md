# Sellers por tienda (Vite)

App React/Vite reconstruida desde cero con datos reales embebidos desde los Excel originales.

## Vercel
- Framework: Vite
- Install command: npm install --no-audit --no-fund
- Build command: npm run build
- Output directory: dist

## Funciones
- Tiendas por solapa: BNA, Macro, Comafi, Ciudad, MasBanco.
- Edición completa por seller.
- Estado como desplegable.
- Exportar XLSX.
- Sin botón importar.
- Cambios guardados en localStorage.
